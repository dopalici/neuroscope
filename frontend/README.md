# NeuroScope frontend

Vite + React + TypeScript UI for NeuroScope (dashboard + Mirror).

Product docs — including **Mirror** (`/mirror`), gestures, baseline, recording, and how to run with or without a Muse — live in the [root README](../README.md).

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173 (dashboard) or http://127.0.0.1:5173/mirror. The backend WebSocket must be running; see the root README quick start.
